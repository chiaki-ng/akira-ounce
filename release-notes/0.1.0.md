First public build of akira for the Switch 2, built with libounce and OunceVK and run under kaiHEN.

## Install

Copy `switch/akira.nro` from the zip to the root of the SD card and launch it from the ounce homebrew menu.

## What works

- Remote Play to a PS5 or PS4 on the local network
- Console registration with the 8 digit PIN, or automatically through PSN
- Hardware H.264 decoding through the libounce video decoder, drawn with OunceVK
- Custom DNS and subnet discovery, including with 90DNS active

## Known issues

- PS Cloud streaming is not included in this build
- The decoder holds at most three H.264 reference frames, so the stream is re-described to the decoder with that limit
- Quitting can crash in the threading provider

## Debug symbols

`akira-ounce-<version>-debug-symbols.zip` holds the unstripped `akira.elf` that matches `akira.nro`, for symbolising crash reports.
